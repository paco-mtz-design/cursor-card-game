# Possible Game Fixes

## True-Strike Lens — card text wording

- **Status:** Pending physical card update
- **Reported on:** 2026-04-20
- **Context:** The Lens card currently reads "ignores terrain effects and Lancer counters." Following the true-strike hierarchy overhaul, the Lens only bypasses *unguaranteed* counters — Rowka and Nyss-guaranteed counters still fire against a Lens attack.
- **Potential fix:** Update printed card text to read "ignores terrain effects and unguaranteed Lancer counters" (or equivalent plain-language wording).
- **Reason to revisit:** Ensure physical card accurately describes the prototype behaviour so players don't assume Lens beats Rowka/Nyss.

## Muzzled Beast + Hidden Information

- **Status:** Pending review
- **Reported on:** 2026-04-12
- **Context:** In digital play, players cannot inspect face-down units, so Muzzled Beast reliably blocks single-use items. In physical play, players could potentially check hidden unit identities and infer/block around this rule.
- **Potential rules adjustment:** Apply Muzzled Beast's single-use-item restriction only if at least one face-up unit of the affected faction is present on board.
- **Reason to revisit:** Improve physical-vs-digital consistency and reduce hidden-information ambiguity.
